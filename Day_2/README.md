# Day 2 - Student Data Analysis (Remote Internship Task)

This folder contains my Day 2 practical task submission for the remote internship.

## 📁 What's in this project

**`main.py`** — A Python + Pandas project that:
- Stores data for 10 students (Name, Age, Course, Marks) using a Python dictionary
- Converts that dictionary into a Pandas DataFrame
- Displays all students
- Filters and shows only students who scored above 70
- Calculates the average marks of all students
- Finds the student with the highest marks
- Finds the student with the lowest marks
- Shows the total number of students

## ▶️ How to Run

Make sure Pandas is installed first:
```bash
pip install pandas
```

Then run the script:
```bash
python main.py
```

## 🛠️ Requirements
- Python 3.x
- pandas
