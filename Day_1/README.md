# Day 1 - Basic Python Project (Remote Internship Task)

This repository contains my Day 1 practical task submission for the remote internship.

## 📁 Project Contents

- **`main.py`** — A basic Python project that:
  - Takes basic information from the user (name, age, city, skills)
  - Stores the information using variables and a list
  - Uses if/else conditions to categorize the user's age and skill count
  - Uses a loop to process the list of skills
  - Uses functions (`get_age_category`, `build_summary`) to organize logic
  - Displays a final formatted summary

- **`AI_ML_DL_GenAI_Concepts.md`** — A short learning file explaining:
  - What is AI?
  - What is Machine Learning?
  - What is Deep Learning?
  - What is Generative AI?
  - One real-world example of each

## ▶️ How to Run

```bash
python main.py
```

You'll be prompted to enter your name, age, city, and a comma-separated list of skills.
The program will then display a summary based on your input.

## 🛠️ Requirements

- Python 3.x (no external libraries needed — uses only Python's built-in features)
